# Licensing & source

This page bundles two engines:

- **AshnasBot** — `net2`, this project's own network + search. MIT.
- **Stauf** — `CellGame` from [ScummVM](https://github.com/scummvm/scummvm)'s Groovie
  engine, the AI from the original *7th Guest* microscope puzzle. **GPLv3-or-later.**

As a result this bundle is conveyed under the **GPLv3**
([full text](./LICENSE.GPLv3)).

## Source

Complete corresponding source — `CellGame`, the WebAssembly wrappers, this page,
and the build rules — is at **https://github.com/ashnasbot/t7g-ml**. Build with
